# Clip Studio — downloads

Builds only. The source lives in a private repository.

## Install

```sh
curl -fsSL https://github.com/Sidharth004/clip-studio-releases/releases/latest/download/install.sh | sh
```

Then run `clip-studio`.

Requires macOS 12 or newer. `ffmpeg` and `yt-dlp` are bundled. Claude Code is
not — the app walks you through installing it on first run, and uses your own
Claude subscription.

Everything runs on your machine. No video and no transcript is uploaded
anywhere.
